      How this site is secured

      • Content Security Policy: only scripts, styles, images and fonts from this site can load, with no inline scripts or third-party code.
      • Safe output: anything you type is shown with textContent, never innerHTML, so it can't run as code.
      • Nothing to steal: no backend, secrets, API keys, cookies or trackers. Your theme choice is the only thing stored, and it stays in your browser.
      • Known limit: GitHub Pages can't set custom security headers, so other sites could frame this page. I accept that risk because there are no logins or sensitive actions here.
